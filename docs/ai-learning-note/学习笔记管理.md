# 学习笔记管理

## 1. 背景与目标

前台 `dnhyxc-ai` 的英语学习模块允许用户创建富文本学习笔记（存储在 `english_learning_note` 表）。后台此前没有管理入口，无法查看或清理用户笔记。本专题实现：

- 新增后台 `ai-learning-note` 模块，以只读方式查看前台业务库学习笔记。
- 与书籍列表一致，按后台用户的 `aiUserId` 做行级隔离：超管看全量，普通用户仅看自己绑定前台账号的笔记。
- 支持富文本 HTML 预览与软删除（物理删除）。
- 种子菜单新增「学习笔记」入口，普通用户角色默认绑定该菜单。

## 3. 实现思路

1. **实体映射**：新建 `AiLearningNote` 实体映射 `english_learning_note` 表，包含 `id`（UUID 主键）、`userId`、`title`、`content`（longtext 富文本）、`isPublic`、时间戳；添加 `userId + updatedAt` 联合索引和 `isPublic` 单列索引以加速查询。
2. **双库注册**：在 `typeorm-ai.config.ts` 的 `entities` 数组中注册 `AiLearningNote`，使其归入 AI 业务库连接；`app.module.ts` 在 `AI_DB_ENABLED` 条件分支中注册 `AiLearningNoteModule`。
3. **行级隔离**：控制器通过 `resolveScope` 方法识别当前用户身份（超管 / 普通用户），生成 `scopeAiUserId`；Service 层对 `null`（未绑定）短路返回空，对具体 id 拼 `andWhere` 做行级过滤——与 `ai-ebook` 模块完全对齐。
4. **作者解析**：Service 的 `resolveAuthors` 方法批量查询 `AiUser` 表，将 `userId` 映射为 `username`，避免 N+1 查询。
5. **删除安全**：普通用户删除时携带 `scopeAiUserId`，确保只能删除自己绑定前台账号下的笔记；超管可删任意笔记。
6. **前端预览**：笔记 `content` 为富文本 HTML，前端用 Ant Design `Modal` + `dangerouslySetInnerHTML` 渲染预览，`prose prose-sm` 样式保证可读性。
7. **种子菜单**：`DEFAULT_MENUS` 新增「学习笔记」条目（`order: 8`），后续菜单顺延；`USER_MENU_PATHS` 追加 `'/ai-learning-note'`，普通用户角色自动绑定。

import {
	Column,
	CreateDateColumn,
	Entity,
	Index,
	PrimaryGeneratedColumn,
	UpdateDateColumn,
} from 'typeorm';

// 实体映射 english_learning_note 表；英语学习 · 学习笔记（富文本 HTML）
@Entity({ name: 'english_learning_note' })
// 联合索引：userId + updatedAt，加速按用户查询并按更新时间排序
@Index('IDX_eln_user_updated', ['userId', 'updatedAt'])
// 单列索引：isPublic，加速公开笔记筛选
@Index('IDX_eln_public', ['isPublic'])
export class AiLearningNote {
	// UUID 主键，与前台表结构一致
	@PrimaryGeneratedColumn('uuid')
	id: string;

	// 关联前台用户 id（对应 AI 库 user.id）
	@Column({ name: 'user_id', type: 'int' })
	userId: number;

	// 笔记标题，可为空
	@Column({ type: 'varchar', length: 200, nullable: true })
	title: string | null;

	// 笔记正文，longtext 存储富文本 HTML
	@Column({ type: 'longtext' })
	content: string;

	// 是否公开，默认 false
	@Column({ name: 'is_public', type: 'boolean', default: false })
	isPublic: boolean;

	// 创建时间，映射 created_at 列
	@CreateDateColumn({ name: 'created_at', type: 'timestamp' })
	createdAt: Date;

	// 更新时间，映射 updated_at 列
	@UpdateDateColumn({ name: 'updated_at', type: 'timestamp' })
	updatedAt: Date;
}

### 4.3 `AiLearningNoteService` 查询与删除逻辑（新增）

**改动后** · `apps/backend/src/services/ai-learning-note/ai-learning-note.service.ts`（当前，全文件，约 L1-L96）

```typescript
// Nest 注入与服务不可用异常
import { Injectable, ServiceUnavailableException } from '@nestjs/common';
// TypeORM 数据源与仓储注入
import { InjectDataSource, InjectRepository } from '@nestjs/typeorm';
// DataSource 与 Repository 类型
import { DataSource, Repository } from 'typeorm';
// AI 业务库连接名常量
import { DB_CONNECTIONS } from '../../database/constants';
// AI 用户实体，用于作者名映射
import { AiUser } from '../ai-user/ai-user.entity';
// 学习笔记实体
import { AiLearningNote } from './ai-learning-note.entity';

// 扩展视图接口：在实体字段基础上增加 author 字段
export interface AiLearningNoteView extends AiLearningNote {
	author: string;
}

@Injectable()
export class AiLearningNoteService {
	constructor(
		// 注入学习笔记仓储，绑定 AI 业务库
		@InjectRepository(AiLearningNote, DB_CONNECTIONS.AI)
		private readonly noteRepository: Repository<AiLearningNote>,
		// 注入 AI 用户仓储，用于批量解析作者名
		@InjectRepository(AiUser, DB_CONNECTIONS.AI)
		private readonly aiUserRepository: Repository<AiUser>,
		// 注入 AI 数据源，用于判断连接是否就绪
		@InjectDataSource(DB_CONNECTIONS.AI)
		private readonly aiDataSource: DataSource,
	) {}

	// 前置检查：AI 业务库是否已连接
	private assertReady() {
		if (!this.aiDataSource?.isInitialized) {
			throw new ServiceUnavailableException(
				'AI 业务库未连接，请确认 dnhyxc-ai MySQL 已启动且 AI_DB_* 配置正确',
			);
		}
	}

	// 批量解析作者名：查 AI 库 user 表，映射 userId → username
	private async resolveAuthors(
		notes: AiLearningNote[],
	): Promise<AiLearningNoteView[]> {
		// 空列表直接返回
		if (notes.length === 0) return [];
		// 收集所有不重复的 userId
		const userIds = [...new Set(notes.map((n) => n.userId))];
		// 一次性查出所有相关用户
		const users = await this.aiUserRepository
			.createQueryBuilder('u')
			.where('u.id IN (:...ids)', { ids: userIds })
			.getMany();
		// 构建 userId → username 映射
		const map = new Map<number, string>();
		for (const u of users) {
			map.set(u.id, u.username);
		}
		// 将每条笔记追加 author 字段
		return notes.map((n) => ({
			...n,
			author: map.get(n.userId) ?? `用户${n.userId}`,
		}));
	}

	// 分页查询学习笔记
	async findAll(query: {
		pageNo?: number;
		pageSize?: number;
		title?: string;
		scopeAiUserId?: number | null;
	}) {
		this.assertReady();

		// 普通用户未绑定前台账号：直接返回空
		if (query.scopeAiUserId === null) {
			return { list: [], total: 0 };
		}

		const pageNo = query.pageNo || 1;
		const pageSize = query.pageSize || 20;

		// 构建 QueryBuilder，按更新时间倒序
		const qb = this.noteRepository
			.createQueryBuilder('eln')
			.orderBy('eln.updatedAt', 'DESC')
			.take(pageSize)
			.skip((pageNo - 1) * pageSize);

		// 普通用户：只查自己绑定前台账号的笔记
		if (query.scopeAiUserId != null) {
			qb.andWhere('eln.userId = :aiUserId', {
				aiUserId: query.scopeAiUserId,
			});
		}
		// 标题模糊搜索
		if (query.title) {
			qb.andWhere('eln.title LIKE :title', { title: `%${query.title}%` });
		}

		// 执行查询并获取总数
		const [list, total] = await qb.getManyAndCount();
		// 批量解析作者名
		const viewList = await this.resolveAuthors(list);
		return { list: viewList, total };
	}

	// 删除笔记：普通用户只能删自己绑定账号的
	async delete(id: string, scopeAiUserId?: number | null) {
		this.assertReady();
		// 构建删除前查询：先查到目标笔记再删
		const qb = this.noteRepository
			.createQueryBuilder('eln')
			.where('eln.id = :id', { id });
		// 普通用户：额外限制 userId，防止越权删除
		if (scopeAiUserId != null) {
			qb.andWhere('eln.userId = :aiUserId', { aiUserId: scopeAiUserId });
		}
		const target = await qb.getOne();
		// 不存在或不属于当前用户：静默返回
		if (!target) return;
		await this.noteRepository.delete(target.id);
	}
}
```

### 4.4 `AiLearningNoteController` 接口与权限隔离（新增）

**改动后** · `apps/backend/src/services/ai-learning-note/ai-learning-note.controller.ts`（当前，全文件，约 L1-L81）

```typescript
// Nest 控制器相关装饰器
import {
	Controller,
	Delete,
	Get,
	Param,
	Query,
	Req,
	UseGuards,
	UseInterceptors,
} from '@nestjs/common';
// class-transformer 类型转换
import { Type } from 'class-transformer';
// class-validator 校验装饰器
import { IsInt, IsOptional, IsString, Min } from 'class-validator';
// Express 请求类型
import type { Request } from 'express';
// 角色装饰器
import { Roles } from '../../decorators/roles.decorator';
// 角色枚举
import { Role } from '../../enum/roles.enum';
// JWT 守卫
import { JwtGuard } from '../../guards/jwt.guard';
// 角色守卫
import { RoleGuard } from '../../guards/role.guard';
// 响应拦截器
import { ResponseInterceptor } from '../../interceptors/response.interceptor';
// 后台用户服务，用于查当前登录用户身份
import { UserService } from '../user/user.service';
// 学习笔记服务
import { AiLearningNoteService } from './ai-learning-note.service';

// 查询参数 DTO：分页 + 标题搜索
class GetLearningNoteQuery {
	@IsOptional()
	@Type(() => Number)
	@IsInt()
	@Min(1)
	pageNo?: number = 1;

	@IsOptional()
	@Type(() => Number)
	@IsInt()
	@Min(1)
	pageSize?: number = 20;

	@IsOptional()
	@IsString()
	title?: string;
}

@Controller('ai-learning-note')
@UseGuards(JwtGuard, RoleGuard)
// ADMIN 和 USER 均可访问（普通用户仅看自己绑定账号的数据）
@Roles(Role.ADMIN, Role.USER)
@UseInterceptors(ResponseInterceptor)
export class AiLearningNoteController {
	constructor(
		private readonly noteService: AiLearningNoteService,
		private readonly userService: UserService,
	) {}

	// 统一的身份解析：返回是否超管与 scopeAiUserId
	private async resolveScope(req: Request & { user?: { userId?: number } }) {
		// 从 JWT userId 反查后台用户
		const adminUser = req.user?.userId
			? await this.userService.findOne(req.user.userId)
			: null;
		// 判定是否超管
		const isAdmin = Boolean(
			adminUser?.roles?.some(
				(r) => r.id === Role.ADMIN || r.name === '超级管理员',
			),
		);
		return {
			isAdmin,
			// 超管 undefined（不过滤）；普通用户取 aiUserId；未绑定则 null（空结果）
			scopeAiUserId: isAdmin ? undefined : (adminUser?.aiUserId ?? null),
		};
	}

	// 查询笔记列表
	@Get('/getNotes')
	async getNotes(
		@Req() req: Request & { user?: { userId?: number } },
		@Query() query: GetLearningNoteQuery,
	) {
		// 解析当前用户范围
		const { scopeAiUserId } = await this.resolveScope(req);
		// 委托给 Service，传入 scopeAiUserId 做行级隔离
		return this.noteService.findAll({ ...query, scopeAiUserId });
	}

	// 删除笔记
	@Delete('/deleteNote/:id')
	async deleteNote(
		@Req() req: Request & { user?: { userId?: number } },
		@Param('id') id: string,
	) {
		// 解析当前用户范围
		const { isAdmin, scopeAiUserId } = await this.resolveScope(req);
		// 超管传 undefined（可删任意）；普通用户传 scopeAiUserId（只能删自己的）
		return this.noteService.delete(id, isAdmin ? undefined : scopeAiUserId);
	}
}
```

	// 判定是否超管，用于控制 UI 文案
	const isAdmin = authStore.isSuperAdmin;
	const [list, setList] = useState<LearningNoteRow[]>([]);
	const [total, setTotal] = useState(0);
	const [pageNo, setPageNo] = useState(1);
	const [pageSize, setPageSize] = useState(DEFAULT_PAGE_SIZE);
	const [title, setTitle] = useState('');
	const [error, setError] = useState('');
	// 富文本预览内容
	const [previewContent, setPreviewContent] = useState<string | null>(null);

	// 加载列表
	const load = async (page = pageNo, size = pageSize) => {
		try {
			setError('');
			// 调后端 getNotes，silent 模式不弹全局错误
			const res = await getAiLearningNotesApi({
				pageNo: page,
				pageSize: size,
				title: title || undefined,
			});
			const data = res.data as { list: LearningNoteRow[]; total: number };
			setList(data.list);
			setTotal(data.total);
			setPageNo(page);
			setPageSize(size);
		} catch (e: any) {
			// 业务库不可用时展示友好错误
			setList([]);
			setTotal(0);
			setError(
				e?.message ||
					'AI 业务库不可用，请确认 AI_DB_ENABLED=true 且 dnhyxc-ai MySQL 已启动',
			);
		}
	};

	// 首次挂载加载第一页
	useEffect(() => {
		load(1, DEFAULT_PAGE_SIZE);
	}, []);
	// ...列定义与 JSX 省略，详见源码

## 5. 兼容性与影响

- 需要前台 `dnhyxc-ai` 数据库中 `english_learning_note` 表已存在；表结构由前台工程维护，后台仅只读 + 删除，不自动建表（`synchronize: false`）。
- 若 `AI_DB_ENABLED=false`，`AiLearningNoteModule` 不会加载，前端访问 `/ai-learning-note` 会因接口 404 报错，页面展示「AI 业务库不可用」提示。
- 普通用户角色首次启动时由 `SeedService` 自动补绑 `/ai-learning-note` 菜单，已有数据库重启后即生效。

## 6. 风险与回归

- 回归建议：
  1. 超管登录 → 侧栏可见「学习笔记」→ 列表加载全量 → 搜索标题 → 预览富文本 → 删除一条。
  2. 普通用户（已绑定）登录 → 仅看到自己绑定前台账号的笔记 → 删除他人笔记返回静默无操作。
  3. 普通用户（未绑定）登录 → 列表为空 + 「尚未绑定前台账号」文案。
  4. `AI_DB_ENABLED=false` 时 → 模块不加载，前端报错提示。
  5. 笔记 `content` 为空 → 「查看」按钮禁用。

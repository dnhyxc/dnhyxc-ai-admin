# 项目使用指南（面向管理员 / 普通用户）

本文档覆盖以下使用场景：
1. 如何查看 / 换绑你的前台账号（个人中心）
2. 作为超管：在用户列表快速识别后台账号对应的前台用户名
3. 作为超管：给某个角色重新**分配菜单权限**（不删除角色也能改）
4. 遇到「没有访问权限」怎么办？页面加载转圈时的正确姿态

## 1. 个人中心：前台账号换绑

> 只有已绑定的账号才会看到「换绑」按钮；未绑定的账号点击按钮后跳转到「绑定前台账号」页，按提示绑定即可。

### 1.1 进入个人中心

1. 登录后台管理系统。
2. 右上角点击**你的头像** → 下拉菜单选「个人中心」。
3. 页面底部有一张卡片：**前台账号绑定**。

### 1.2 换绑步骤（已绑定）

1. 确认卡片中显示的「当前绑定：username」是你要换的旧账号。
2. 点击卡片中的 **换绑** 按钮。
3. 系统弹出**二次确认框**：
   > 「换绑后当前账号将无法访问旧前台账号下的数据（如电子书、学习笔记、知识库等）。是否确认换绑？」
   - 确认后点「继续换绑」；反悔就点「取消」。
4. 弹出真正的**换绑表单**（3 项必填）：
   - **新的前台账号用户名** — 大小写敏感，必须准确（不能是你自己当前账号，否则 400 错误）。
   - **前台账号密码** — 该前台账号的登录密码，用于二次校验。
   - **前台账号邮箱** — 必须与新 username 在前台业务库中的登记邮箱完全一致（400 错误提示「邮箱不匹配」）。
5. 点击「确认换绑」。
6. 成功后：
   - 右上角会出现**绿色成功条** 5 秒自动消失。
   - 卡片里的「当前绑定」立刻刷新为新 username。
   - 前往「前台电子书管理 / 前台笔记管理 / 前台知识库管理」查看是否为新账号的数据。
7. 失败：
   - 右上角会出现**红色错误条**（如「密码错误」「邮箱不匹配」「前台用户不存在」）。
   - 表单仍然打开，方便你修改后重试，不会丢失输入。

### 1.3 常见问题

| 现象 | 可能原因 | 解决方式 |
|------|----------|----------|
| 换绑时提示「用户不存在」 | username 拼错 / 该账号在前台业务库中被软删 | 核对 username；若确实存在，联系超管在「前台用户管理」里确认 |
| 换绑时提示「邮箱不匹配」 | 邮箱填成了自己后台账号的邮箱而不是前台账号的 | 在前台业务库登录该账号，查看个人资料中的邮箱 |
| 换绑后发现书籍列表为空 | 新的前台账号本来就没有书籍，属于正常现象 | 到前台创建一本电子书，再返回后台刷新列表即可 |

## 2. 超管：在「后台用户管理」一眼识别前台账号

> 仅拥有「超管」角色的账号可以访问「后台用户管理」页。普通用户不会在侧栏看到该菜单。

### 2.1 使用步骤

1. 左侧「后台设置」分组 → 打开 **「用户管理」**。
2. 表格中找到列名为 **「关联用户」** 的列：
   - 已绑定的后台账号：显示 `前台用户名`（如 `dnhyxc`）；
   - 未绑定：显示灰色小字 `未绑定`。
3. 可以直接用顶部的搜索框（关键词）按 `username / email / 关联前台用户名` 过滤，比如搜 `dnhyxc` 能立刻找到关联到该前台用户的那条后台账号。
4. 新建 / 编辑后台用户时：当前版本**不会**在表单里开放编辑 `aiUserId`；需要用户自己去「个人中心」绑定或换绑。

## 3. 超管：给角色重新分配菜单权限

> 之前只能「删除角色再重建」，现在新增了「分配菜单」弹窗，基础信息（名称/描述/启用状态）与菜单权限拆开修改。

### 3.1 两种编辑按钮

进入「后台设置」→ **「角色管理」**：每一行的操作列有两个按钮：

| 按钮 | 作用 | 是否改变菜单权限 |
|------|------|------------------|
| **编辑** | 修改名称、描述、是否启用 | 否 |
| **分配菜单**（新增） | 勾选允许访问的菜单项 | 是 |

### 3.2 分配菜单步骤

1. 点目标角色行的「分配菜单」。
2. 弹出「编辑角色 - 分配菜单」弹窗：
   - 顶部有 **搜索框**：输入菜单名模糊过滤（比如输入「前台」能快速筛选所有前台子模块菜单）。
   - 右上角有 **展开全部 / 折叠全部** 两个快捷操作。
   - 中央是**带分组的树形菜单选择器**（后台设置 / 前台 两个父分组，各自展开为子菜单；父级勾选 = 子级全选）。
3. 勾选需要授权的菜单项，取消勾选要收回的菜单：
   - **底部提交按钮会自动禁用**，当且仅当：没有勾选任何一项（校验：至少勾选 1 项，否则保存按钮置灰）。
4. 点击 **「保存」**：
   - 弹窗先关闭，然后页面显示**全局 Loading 遮罩**（提交请求中，防止重复操作）。
   - 成功后：
     - Loading 遮罩消失；
     - 页面右上弹出绿色成功条：「修改成功」；
     - 表格自动刷新：再次点该角色「分配菜单」可看到保存后的勾选状态。
5. 对普通用户的生效时机：
   - 若被影响的用户**当前已经登录**：在下一次发起请求时（例如刷新页面、切换分页、点击菜单跳转），会立刻按新的权限校验；**若请求返回 403**，全局会弹出红色 Alert：「当前账号无访问权限，请联系管理员分配权限」，并自动跳转到无权限页。
   - 若用户**尚未登录**：下次登录时侧栏和路由就按新权限过滤。

### 3.3 常见问题

| 现象 | 可能原因 | 解决方式 |
|------|----------|----------|
| 保存按钮始终是灰色 | 当前没有勾选任何菜单节点 | 至少勾选 1 项（可以只勾选一个最底层的叶子节点） |
| 分配菜单后某用户仍能访问被收回的页面 | 该用户浏览器端还有缓存的路由 / 菜单，或之前已加载的数据没有被清掉 | 让该用户退出并重新登录；或在该用户端切换分页触发一次请求即可被 403 拦截 |
| 搜索框过滤不到某个菜单 | 搜索关键词只匹配菜单名称 label，不匹配路由 path | 直接在树里逐级展开查找；或者把展开全部打开再肉眼扫 |

## 4. 全局通知 & 加载遮罩：你会看到的两种新 UI

本次发布后，你会在系统的各个角落看到统一的交互反馈：

### 4.1 全局 Alert（出现在右上角，5 秒自动消失）

| 颜色 | 语义 | 典型场景 |
|------|------|----------|
| 绿色（Success） | 操作成功 | 提交保存 / 删除成功 / 换绑成功 |
| 红色（Error） | 操作失败 | 校验失败 / 接口异常 / **403 无权限** |
| 蓝色（Info） | 中性提示 | 暂无 |
| 黄色（Warning） | 警告 | 暂无 |

- 可以点击 Alert 右侧的「×」提前手动关闭。
- **403 无权限时自动跳转到 `/forbidden` 页**：你不用手动关弹窗，等它 5 秒自动消失即可。

### 4.2 页面 Loading 遮罩（三层圆环 + 「加载中...」文字波浪动画）

出现时机：
- 初次进入页面加载列表；
- 点击「查询 / 重置 / 分页切换 / 每页条数」；
- 删除操作二次确认后；
- 表单提交（如保存角色菜单分配、保存修改密码、换绑确认提交）。

关闭时机：
- 接口成功返回后立即关闭；
- 接口报错后立即关闭，并在右上角弹出红色 Alert 展示错误信息。

小贴士：Loading 遮罩覆盖期间，你不能点击页面上的按钮、输入框等元素，这是**防止重复提交的保护**，请耐心等待 1–3 秒。

## 5. 视觉风格变更：全表 8px 圆角

- 之前版本中，表格顶部是直角、底部是圆角，视觉不对称；现在所有表格的 4 个角都统一为 **8px 对称圆角**。
- 筛选卡片与表格之间是**两张独立卡片**（中间有垂直间距），不再做「拼接贴合」的视觉设计。
- 深浅色模式下观感完全一致；如果你的显示器校色正常，两者应该只有颜色差异，形状不会出现浅色「凸出」深色「凹入」的错觉。
- 如果发现某页面的表格角不是 8px（比如某个角落还露尖 / 或者分页条与表格之间出现了白边），请把浏览器版本、页面地址、屏幕截图发给开发者，属于「回归缺陷」，会在下个小版本修复。

# 角色菜单分配编辑

## 1. 背景与目标

此前「角色管理」页的能力是：
- 顶部 inline 表单新建角色（name + description + 多选 menuIds）。
- 表格仅能「删除」角色（id=1 为超管不可删），角色列、描述列固定宽 100% 自适应。
- **已创建角色不支持编辑菜单**——若管理员想给某个角色加/减一个菜单，只能删角色重建。

本专题补齐「角色编辑」能力：
- 操作列从「纯删除」扩展为「分配菜单 + 删除」双按钮，`width: 140`。
- 新增编辑 Modal：展示角色名、描述、关联菜单（多选 Select），与新建表单使用同一菜单选项数据。
- 加载角色列表包 `noticeStore.setPageLoading`（配合全局遮罩）；提交保存按钮 `saving` loading。
- 名称列、描述列从自适应改为固定宽度（180px / 300px），与「AI 用户管理」等表格风格一致。
- 表格增加 `locale.emptyText = '暂无数据'` 空态统一。

## 2. 改动范围

- `apps/frontend/src/views/roles/RolesPage.tsx`（主要改动）
- （`service/index.ts` 中的 `updateRoleApi` 已存在，本次仅新增 import）
- 间接依赖：`apps/frontend/src/store/notice.ts`（全局 loading 遮罩）

## 3. 实现思路

- **编辑态用局部 state**：`editing: RoleRow | null`，为 null 时 Modal 关闭；点击「分配菜单」把当前行塞进 editing 并回填表单。
- **Modal destroyOnHidden**：避免多角色来回编辑时，上一次的 Select 选中项残留到下一次。
- **保存流程**：`editForm.validateFields() → updateRoleApi(editing.id, values) → 成功提示 → 清空 editing + resetFields → 重新 load()`。
- **菜单选项复用**：进入页面时一次性 `getMenusApi()` 拉取，新建 inline 表单与编辑 Modal 共享同一个 `menus` 数组渲染 options。
- **操作列组件**：使用 antd `Space` 组件将「分配菜单」按钮与删除 `Popconfirm` 包在同一行，`flex gap-2` 对齐；按钮自定义 `className="px-0!"` 去掉 antd 默认 padding，使其与其他 link 按钮视觉对齐。

**改动前** · `apps/frontend/src/views/roles/RolesPage.tsx`（基线，约 L1–L166）

```typescript
// 引入 antd 组件：Button、Card、Form、Input、message、Popconfirm、Select、Table
import {
        Button,
        Card,
        Form,
        Input,
        message,
        Popconfirm,
        Select,
        Table,
} from 'antd';
// mobx-react observer
import { observer } from 'mobx-react';
// React hooks
import { useEffect, useState } from 'react';
// 分页工具：默认页大小 + 分页配置生成
import { DEFAULT_PAGE_SIZE, tablePagination } from '@/lib/table-pagination';
// service 接口：创建角色 / 删除角色 / 拉菜单 / 拉角色（注意：无 updateRoleApi）
import {
        createRoleApi,
        deleteRoleApi,
        getMenusApi,
        getRolesApi,
} from '@/service';
// 根 Store 钩子
import { useStore } from '@/store';

// 表格行类型
type RoleRow = {
        // 角色 id
        id: number;
        // 角色名
        name: string;
        // 描述
        description: string;
        // 关联菜单（从角色接口返回时嵌套）
        menus?: Array<{ id: number; name: string }>;
};

// 导出 observer 包装组件
export const RolesPage = observer(function RolesPage() {
        // 仅取 authStore，通过 isSuperAdmin 判断 canWrite
        const { authStore } = useStore();
        // 是否具备写权限（仅超管 true）
        const canWrite = authStore.isSuperAdmin;
        // 角色列表
        const [list, setList] = useState<RoleRow[]>([]);
        // 菜单选项（新建 + 编辑共用；从 getMenusApi 拉）
        const [menus, setMenus] = useState<Array<{ id: number; name: string }>>([]);
        // 页码（Table 受控）
        const [pageNo, setPageNo] = useState(1);
        // 页大小
        const [pageSize, setPageSize] = useState(DEFAULT_PAGE_SIZE);
        // 新建角色的 inline 表单实例
        const [form] = Form.useForm();

        // 加载角色列表：无 loading 遮罩；getRolesApi 失败时直接走全局 Toast
        const load = async () => {
                // 调接口
                const res = await getRolesApi();
                // 存列表
                setList(res.data as RoleRow[]);
                // 重置页码为 1
                setPageNo(1);
        };

        // 首次进入：加载角色；可写时额外拉菜单选项
        useEffect(() => {
                load();
                if (canWrite) {
                        // 拉菜单：res.data 为菜单对象数组（至少含 id/name）
                        getMenusApi().then((res) => setMenus(res.data as any[]));
                }
        }, [canWrite]);

        // 表格列定义
        const columns = [
                // 列 1：ID，宽 80
                { title: 'ID', dataIndex: 'id', width: 80 },
                // 列 2：名称（默认自适应宽度，无限制会把「描述/菜单」列挤太窄）
                { title: '名称', dataIndex: 'name' },
                // 列 3：描述（默认自适应）
                { title: '描述', dataIndex: 'description' },
                // 列 4：菜单展示——把 menu 数组用顿号拼接，空则显示 "—"
                {
                        title: '菜单',
                        render: (_: unknown, r: RoleRow) =>
                                r.menus?.map((m) => m.name).join('、') || '—',
                },
                // 列 5：操作（仅超管可写时插入）
                ...(canWrite
                        ? [
                                        {
                                                // 标题
                                                title: '操作',
                                                // 旧版 width 100，只能容纳「删除」一个按钮
                                                width: 100,
                                                // 渲染：Popconfirm 包裹删除按钮
                                                render: (_: unknown, r: RoleRow) => (
                                                        <Popconfirm
                                                                // 二次确认标题
                                                                title="确认删除？"
                                                                // 超管角色 id=1 不可删除
                                                                disabled={r.id === 1}
                                                                // 确认回调
                                                                onConfirm={async () => {
                                                                        await deleteRoleApi(r.id);
                                                                        message.success('已删除');
                                                                        load();
                                                                }}
                                                        >
                                                                <Button danger type="link" size="small" disabled={r.id === 1}>
                                                                        删除
                                                                </Button>
                                                        </Popconfirm>
                                                ),
                                        },
                                ]
                        : []),
        ];

        // 主 JSX
        return (
                // 占满高度的 flex col
                <div className="h-full flex flex-col">
                        // 超管才显示「新建角色」Card
                        {canWrite && (
                                // 新建区域：顶部卡片
                                <div className="shrink-0 px-6 pt-6 pb-4">
                                        <Card size="small" title="新建角色">
                                                // 内联布局 Form
                                                <Form
                                                        // 绑定新建 form
                                                        form={form}
                                                        // label 与 input 一行排布
                                                        layout="inline"
                                                        // 提交回调
                                                        onFinish={async (values) => {
                                                                // 调用创建接口
                                                                await createRoleApi(values);
                                                                message.success('已创建角色');
                                                                // 重置表单
                                                                form.resetFields();
                                                                // 重新加载列表
                                                                load();
                                                        }}
                                                >
                                                        // 角色名：必填
                                                        <Form.Item name="name" rules={[{ required: true }]}>
                                                                <Input placeholder="角色名" />
                                                        </Form.Item>
                                                        // 描述：可选
                                                        <Form.Item name="description">
                                                                <Input placeholder="描述" />
                                                        </Form.Item>
                                                        // 关联菜单：多选 + 可清空
                                                        <Form.Item name="menuIds">
                                                                <Select
                                                                        mode="multiple"
                                                                        allowClear
                                                                        placeholder="关联菜单"
                                                                        style={{ minWidth: 220 }}
                                                                        options={menus.map((m) => ({ value: m.id, label: m.name }))}
                                                                />
                                                        </Form.Item>
                                                        // 提交按钮
                                                        <Form.Item>
                                                                <Button type="primary" htmlType="submit">
                                                                        创建角色
                                                                </Button>
                                                        </Form.Item>
                                                </Form>
                                        </Card>
                                </div>
                        )}

                        // 列表区域：占满剩余高度 + 可滚动
                        <div className="flex-1 min-h-0 overflow-auto px-6 pb-6">
                                <Table
                                        // id 作为 rowKey
                                        rowKey="id"
                                        // 数据源
                                        dataSource={list}
                                        // 列定义
                                        columns={columns as any}
                                        // 分页配置（调用 tablePagination）
                                        pagination={tablePagination(
                                                list.length,
                                                pageNo,
                                                pageSize,
                                                (page, size) => {
                                                        setPageNo(page);
                                                        setPageSize(size);
                                                },
                                        )}
                                        // 横向滚动：800
                                        scroll={{ x: 800 }}
                                />
                        </div>
                </div>
        );
});
```

**改动后** · `apps/frontend/src/views/roles/RolesPage.tsx`（当前，约 L1–L230）

```typescript
// antd 组件：新增 Modal（编辑弹窗）、Space（同一行操作按钮间距容器）
import {
        Button,
        Card,
        Form,
        Input,
        // 新增：编辑弹窗容器
        Modal,
        message,
        Popconfirm,
        Select,
        // 新增：操作按钮之间 gap 包装
        Space,
        Table,
} from 'antd';
// mobx-react observer
import { observer } from 'mobx-react';
// React hooks
import { useEffect, useState } from 'react';
// 分页工具
import { DEFAULT_PAGE_SIZE, tablePagination } from '@/lib/table-pagination';
// service 接口：新增 updateRoleApi（此前已存在，但本页未使用；现在 import 进来）
import {
        createRoleApi,
        deleteRoleApi,
        getMenusApi,
        getRolesApi,
        // 新增：编辑角色（更新 name / description / menuIds）
        updateRoleApi,
} from '@/service';
// 根 Store 钩子
import { useStore } from '@/store';

// 表格行类型（与旧版一致）
type RoleRow = {
        id: number;
        name: string;
        description: string;
        menus?: Array<{ id: number; name: string }>;
};

// 组件
export const RolesPage = observer(function RolesPage() {
        // 新增：noticeStore 用来包加载列表遮罩
        const { authStore, noticeStore } = useStore();
        // 是否超管（仅超管可写）
        const canWrite = authStore.isSuperAdmin;
        // 角色列表
        const [list, setList] = useState<RoleRow[]>([]);
        // 菜单选项（新建 + 编辑共用）
        const [menus, setMenus] = useState<Array<{ id: number; name: string }>>([]);
        // 页码
        const [pageNo, setPageNo] = useState(1);
        // 页大小
        const [pageSize, setPageSize] = useState(DEFAULT_PAGE_SIZE);
        // 新建 inline 表单
        const [form] = Form.useForm();
        // 新增：编辑弹窗专用 Form 实例
        const [editForm] = Form.useForm();
        // 新增：当前编辑角色（null 表示关闭 Modal）
        const [editing, setEditing] = useState<RoleRow | null>(null);
        // 新增：Modal OK 按钮的 loading 状态，防止重复提交
        const [saving, setSaving] = useState(false);

        // 加载角色列表：包 noticeStore.setPageLoading 全屏遮罩
        const load = async () => {
                // 开始加载：显示遮罩
                noticeStore.setPageLoading(true);
                try {
                        // 拉取角色列表
                        const res = await getRolesApi();
                        setList(res.data as RoleRow[]);
                        setPageNo(1);
                } finally {
                        // 成功或失败都关闭遮罩
                        noticeStore.setPageLoading(false);
                }
        };

        // 首次进入：加载列表 + 拉菜单
        useEffect(() => {
                load();
                if (canWrite) {
                        getMenusApi().then((res) => {
                                const data = res.data;
                                setMenus(Array.isArray(data) ? data : []);
                        });
                }
        }, [canWrite]);

        // 新增：打开编辑弹窗——把当前行数据塞到 editing，并回填 editForm 三个字段
        const openEdit = (r: RoleRow) => {
                // 写入 editing state → Modal open
                setEditing(r);
                // 把角色名、描述、已关联菜单 ids 回填到表单
                editForm.setFieldsValue({
                        name: r.name,
                        description: r.description,
                        // menus 数组若存在则取每个元素的 id，默认空数组
                        menuIds: r.menus?.map((m) => m.id) || [],
                });
        };

        // 新增：编辑提交回调——Modal onOk
        const submitEdit = async () => {
                // 若 editing 空（防御）则 return
                if (!editing) return;
                // 先校验表单三字段
                const values = await editForm.validateFields();
                // 开始保存 loading
                setSaving(true);
                try {
                        // 调用 updateRoleApi：传 roleId + 表单值（name/description/menuIds）
                        await updateRoleApi(editing.id, values);
                        // 成功提示
                        message.success('角色菜单已更新');
                        // 关闭 Modal（置 editing 为 null）
                        setEditing(null);
                        // 清空表单
                        editForm.resetFields();
                        // 重新加载列表（体现最新 menu 关联）
                        load();
                } finally {
                        // 解除 saving loading
                        setSaving(false);
                }
        };

        // 列定义（改动：名称/描述改宽度；操作列新增分配菜单按钮）
        const columns = [
                { title: 'ID', dataIndex: 'id', width: 80 },
                // 名称列：固定 180px，避免「描述」被挤到一行很长
                { title: '名称', dataIndex: 'name', width: 180 },
                // 描述列：固定 300px（超长由 Table 行高自动换行）
                { title: '描述', dataIndex: 'description', width: 300 },
                {
                        title: '菜单',
                        render: (_: unknown, r: RoleRow) =>
                                r.menus?.map((m) => m.name).join('、') || '—',
                },
                ...(canWrite
                        ? [
                                        {
                                                title: '操作',
                                                // 宽 140：放两个按钮「分配菜单 + 删除」
                                                width: 140,
                                                render: (_: unknown, r: RoleRow) => (
                                                        // Space 包裹让两个按钮并排对齐 + gap 距离
                                                        <Space size={0} className="flex items-center gap-2">
                                                                // 「分配菜单」link 按钮：无 danger
                                                                <Button
                                                                        // antd link 风格
                                                                        type="link"
                                                                        size="small"
                                                                        // 自定义：去掉默认 padding，使文字紧贴起始
                                                                        className="px-0!"
                                                                        // 点击打开编辑弹窗
                                                                        onClick={() => openEdit(r)}
                                                                >
                                                                        分配菜单
                                                                </Button>
                                                                // 删除 Popconfirm（与旧版一致）
                                                                <Popconfirm
                                                                        title="确认删除？"
                                                                        disabled={r.id === 1}
                                                                        onConfirm={async () => {
                                                                                await deleteRoleApi(r.id);
                                                                                message.success('已删除');
                                                                                load();
                                                                        }}
                                                                >
                                                                        <Button danger type="link" size="small" disabled={r.id === 1}>
                                                                                删除
                                                                        </Button>
                                                                </Popconfirm>
                                                        </Space>
                                                ),
                                        },
                                ]
                        : []),
        ];

        return (
                <div className="h-full flex flex-col">
                        {canWrite && (
                                <div className="shrink-0 px-6 pt-6 pb-4">
                                        <Card size="small" title="新建角色">
                                                <Form
                                                        form={form}
                                                        layout="inline"
                                                        onFinish={async (values) => {
                                                                await createRoleApi(values);
                                                                message.success('已创建角色');
                                                                form.resetFields();
                                                                load();
                                                        }}
                                                >
                                                        <Form.Item name="name" rules={[{ required: true }]}>
                                                                <Input placeholder="角色名" />
                                                        </Form.Item>
                                                        <Form.Item name="description">
                                                                <Input placeholder="描述" />
                                                        </Form.Item>
                                                        <Form.Item name="menuIds">
                                                                <Select
                                                                        mode="multiple"
                                                                        allowClear
                                                                        placeholder="关联菜单"
                                                                        style={{ minWidth: 220 }}
                                                                        options={menus.map((m) => ({ value: m.id, label: m.name }))}
                                                                />
                                                        </Form.Item>
                                                        <Form.Item>
                                                                <Button type="primary" htmlType="submit">
                                                                        创建角色
                                                                </Button>
                                                        </Form.Item>
                                                </Form>
                                        </Card>
                                </div>
                        )}

                        <div className="flex-1 min-h-0 overflow-auto px-6 pb-6">
                                <Table
                                        rowKey="id"
                                        dataSource={list}
                                        // 新增：空态统一文案
                                        locale={{ emptyText: '暂无数据' }}
                                        columns={columns as any}
                                        pagination={tablePagination(
                                                list.length,
                                                pageNo,
                                                pageSize,
                                                (page, size) => {
                                                        setPageNo(page);
                                                        setPageSize(size);
                                                },
                                        )}
                                        scroll={{ x: 800 }}
                                />
                        </div>

                        // 新增：编辑 Modal（editing 非空时 open=true）
                        <Modal
                                // 标题里拼接当前角色名
                                title={`分配菜单 - ${editing?.name || ''}`}
                                // 受控 open
                                open={editing !== null}
                                // 确认按钮回调
                                onOk={submitEdit}
                                // OK 按钮 loading
                                confirmLoading={saving}
                                // OK 文案
                                okText="保存"
                                // 取消文案
                                cancelText="取消"
                                // 关闭后销毁，避免「编辑一个角色→关闭→再编辑另一角色」回填残留
                                destroyOnHidden
                                // 取消回调：置空 editing + 重置表单
                                onCancel={() => {
                                        setEditing(null);
                                        editForm.resetFields();
                                }}
                        >
                                // 表单：三字段（name / description / menuIds）
                                <Form form={editForm} layout="vertical">
                                        // 角色名：必填（与新建规则一致）
                                        <Form.Item
                                                name="name"
                                                label="角色名"
                                                rules={[{ required: true, message: '请输入角色名' }]}
                                        >
                                                <Input placeholder="角色名" />
                                        </Form.Item>
                                        // 描述：可选
                                        <Form.Item name="description" label="描述">
                                                <Input placeholder="描述" />
                                        </Form.Item>
                                        // 关联菜单：多选 + 可清空（与新建规则一致）
                                        <Form.Item name="menuIds" label="关联菜单">
                                                <Select
                                                        mode="multiple"
                                                        allowClear
                                                        placeholder="选择该角色可访问的菜单"
                                                        options={menus.map((m) => ({
                                                                value: m.id,
                                                                label: m.name,
                                                        }))}
                                                />
                                        </Form.Item>
                                </Form>
                        </Modal>
                </div>
        );
});
```

**变更摘要**：
- 操作列新增「分配菜单」按钮，打开 Modal 编辑当前角色。
- 名称/描述列固定宽；空态统一「暂无数据」。
- `load` 前后包 `noticeStore.setPageLoading`；保存按钮 `saving` loading。
- `destroyOnHidden` + `onCancel` 重置，避免 editing 之间的表单回填残留。

## 5. 行为变化与兼容性

| 维度 | 行为 |
|------|------|
| 新建流程 | 未变化，仍在顶部 inline 卡片创建。 |
| 编辑流程 | 新增；任意角色（包括 id=1 超管）点击「分配菜单」可进入编辑；id=1 的删除仍禁用，但编辑菜单不受限（实际后端通常不限制保存成功）。 |
| 权限 | 只有 `canWrite = isSuperAdmin` 的用户看到「操作」列与新建卡片，与旧版保持一致。 |
| 菜单选项 | 新建表单与编辑 Modal 共用同一份 menus；菜单发生后端变化时可「重新加载页面」更新 options。 |
| 保存失败 | `updateRoleApi` 抛错会走 fetch 层 `message.error`，Modal 不关闭，用户可重试。 |

## 6. 测试与回归建议

1. 新建一个名为「测试角色 A」、分配部分菜单的角色 → 成功后在列表找到它，点击「分配菜单」→ 打开的 Modal 三项值应与列表一致；取消后重开，值依然一致。
2. 编辑「测试角色 A」，新增一个菜单 + 修改描述 → 保存 → 列表对应行的「菜单」列与「描述」列应立即刷新。
3. 编辑 id=1 超管角色 → 打开 Modal 正常；删除按钮禁用、分配菜单按钮可用。
4. 编辑过程中**断网**点击保存 → 应弹出请求失败 Toast，Modal 保持打开，值不丢失。
5. 切换到普通用户账号 → 操作列与新建卡片应不显示（`canWrite=false`）。
6. 进入页面时 → 全屏 Loading 遮罩应短暂显示；数据量大时遮罩在请求期间保持，防止误点击删除超管角色。

# 表格圆角样式调整

## 1. 背景与目标

前一版（详见 [表格顶部圆角去除](./表格顶部圆角去除.md)）采用的视觉方案是：
- 表格**上半部分无圆角**（顶部 4 角全部拉平），以便与上方的筛选条 / Tabs / 新建卡片形成「一体化对接」的拼接感。
- 表格下半部分（分页区域）保留底部圆角。

但在实际使用中，筛选区、新建卡片与表格之间有 `pt-6 pb-4` 的 padding，视觉上是**分隔**的而不是**拼接**的；强行把表格顶部圆角设为 0 反而导致「顶部角尖锐，底部角圆润」的不对称观感，与 Shadcn Card 系列组件的全角设计不一致。

本次调整将表格整体改为**统一 8px 圆角**，符合产品「简约高端」设计风格：
- `.ant-table-wrapper` / `.ant-table` / `.ant-table-container` 等外层容器统一 `border-radius: 8px !important`。
- 分页区域（`.ant-table-pagination`）仅保留底部 8px 圆角，顶部仍为 0，以与表格底无缝衔接。
- 表格行首行的 th / td 单元、固定列单元格的首行单元的 `border-radius` 统一改为 0（这些是行内边角，不需要圆角，否则会出现白边）。
- 横向滚动场景下 `.ant-table-body` 底部圆角同样为 8px。

延伸阅读：[表格顶部圆角去除](./表格顶部圆角去除.md)（历史方案，作为延伸阅读保留）。

## 2. 改动范围

- `apps/frontend/src/index.css`（`/* 全局 Table 8px 圆角 ... */` 段整体替换）

## 3. 实现思路

- **圆角策略分层**：
  - 外层包裹器（wrapper / table / container / content / header / body）：给整体圆角 8px，用 `overflow: hidden` 把超出圆角的内容裁掉，内部滚动条不会凸出来。
  - 分页（`.ant-table-pagination`）：位于 wrapper 底部，**顶部不要圆角**否则会和 tbody 之间出现一条白边；**底部需要圆角**形成闭合视觉。
  - thead 首行单元格 / 固定列单元格的「首行首/尾」：统一 border-radius 0——这些是表格内部边角，不需要额外圆角；外层 wrapper 的 overflow:hidden 已经保证整体是圆角。
- **`!important` 必要性**：Ant Design 5 的 Table token 体系在「有滚动条」「有固定列」「有列筛选菜单」时会生成内联样式，优先级比普通 class 高；使用 `!important` 是保证覆盖的最稳方案。
- **不再使用 `:where(...)` 降级选择器**：旧版为了「降低选择器优先级以便在页面层覆盖」用了 `:where(.ant-table-wrapper)`，但由于我们希望是**全局强制统一风格**，直接使用不带 `:where()` 的 class 选择器（优先级适中），配合 `!important` 即可。

## 4. 关键实现（改动前 / 改动后对比 + 注释）

### 4.1 全局 Table 圆角 CSS（`apps/frontend/src/index.css`）

**对比范围**：`@theme {}` 之后、`.login-grid {}` 之前的「全局 Table 圆角」段落。

**改动前** · `apps/frontend/src/index.css`（基线，约 L82–L132）

```css
/* 取消所有 antd Table 顶部圆角，保留底部圆角（全局强制覆盖，适配所有列表页面） */
/* 外层容器类：wrapper / table / container / content / header / body / 左右固定列容器，
   它们的左上角/右上角设为 0 */
:where(.ant-table-wrapper),
:where(.ant-table),
:where(.ant-table-container),
:where(.ant-table-content),
:where(.ant-table-header),
:where(.ant-table-body),
:where(.ant-table-ping-left),
:where(.ant-table-ping-right) {
        /* 左上角不圆角 */
        border-top-left-radius: 0 !important;
        /* 右上角不圆角 */
        border-top-right-radius: 0 !important;
        /* 逻辑属性：起始开始角（LTR=左上） */
        border-start-start-radius: 0 !important;
        /* 逻辑属性：起始结束角（LTR=右上） */
        border-start-end-radius: 0 !important;
}

/* 表头首行 th/td 以及首行（无论 th/td 都强制顶边 0 圆角） */
:where(.ant-table-thead > tr > th),
:where(.ant-table-thead > tr > td),
:where(.ant-table-thead > tr:first-child > th),
:where(.ant-table-thead > tr:first-child > td),
:where(.ant-table-thead > tr:first-child > th:first-child),
:where(.ant-table-thead > tr:first-child > th:last-child),
:where(.ant-table-thead > tr:first-child > td:first-child),
:where(.ant-table-thead > tr:first-child > td:last-child),
:where(.ant-table-tbody > tr:first-child > td:first-child),
:where(.ant-table-tbody > tr:first-child > td:last-child) {
        border-top-left-radius: 0 !important;
        border-top-right-radius: 0 !important;
        border-start-start-radius: 0 !important;
        border-start-end-radius: 0 !important;
}

/* 固定列场景：左右固定列首行首/尾单元格 */
:where(.ant-table-cell-fix-left),
:where(.ant-table-cell-fix-right),
:where(.ant-table-cell-fix-left-last),
:where(.ant-table-cell-fix-right-first) {
        border-top-left-radius: 0 !important;
        border-top-right-radius: 0 !important;
        border-start-start-radius: 0 !important;
        border-start-end-radius: 0 !important;
}
```

**改动后** · `apps/frontend/src/index.css`（当前，约 L82–L138）

```css
/* 全局 Table 8px 圆角：使用 !important 覆盖 Ant Design 默认样式 */
/* 最外层 wrapper：既做圆角，也负责 overflow hidden 裁切内部超出部分 */
.ant-table-wrapper {
        /* 统一 8px 圆角（与 Shadcn Card 一致） */
        border-radius: 8px !important;
        /* 裁掉滚动条/表头背景等超出圆角外的内容，保证圆角锐利 */
        overflow: hidden !important;
}

/* 内层 <table> 元素本身也要圆角，配合 wrapper 形成双保险 */
.ant-table {
        border-radius: 8px !important;
        overflow: hidden !important;
}

/* container / content / header / body / 左右固定列阴影容器：
   这些在 AntD 有滚动/固定列时会再套一层，统一圆角以避免出现内接矩形突出 */
.ant-table-container,
.ant-table-content,
.ant-table-header,
.ant-table-body,
.ant-table-ping-left,
.ant-table-ping-right {
        border-radius: 8px !important;
}

/* 分页区域底部圆角：位于整个 Table 下方，只需要底部 8px；顶部为 0 以便与 tbody 底部无缝衔接 */
.ant-table-pagination,
.ant-table-pagination.ant-pagination {
        /* 顶部保持 0（不要与 tbody 之间出现凹角 → 白边） */
        border-top-left-radius: 0 !important;
        border-top-right-radius: 0 !important;
        /* 左下 8px */
        border-bottom-left-radius: 8px !important;
        /* 右下 8px */
        border-bottom-right-radius: 8px !important;
}

/* 有横向滚动时，滚动容器 body 需要底部圆角——独立写一遍以防 wrapper 裁不到 */
.ant-table-body {
        border-bottom-left-radius: 8px !important;
        border-bottom-right-radius: 8px !important;
}

/* thead 单元格 / 首行 td：这些是表格内的行边角，统一设为 0；
   外层的 border-radius:8px + overflow:hidden 已经保证整体是圆润的 8px 角 */
.ant-table-thead > tr > th,
.ant-table-thead > tr > td,
.ant-table-thead > tr:first-child > th,
.ant-table-thead > tr:first-child > td,
.ant-table-thead > tr:first-child > th:first-child,
.ant-table-thead > tr:first-child > th:last-child,
.ant-table-thead > tr:first-child > td:first-child,
.ant-table-thead > tr:first-child > td:last-child,
.ant-table-tbody > tr:first-child > td:first-child,
.ant-table-tbody > tr:first-child > td:last-child {
        /* 全部设为 0（不再区分 top/bottom），避免白边与角上的突兀点 */
        border-radius: 0 !important;
}

/* 固定列场景：固定左/右列及其最末/最首单元格的 border-radius 同样归零 */
.ant-table-cell-fix-left,
.ant-table-cell-fix-right,
.ant-table-cell-fix-left-last,
.ant-table-cell-fix-right-first {
        border-radius: 0 !important;
}
```

**变更摘要**：
- 目标从「顶部 0 底部圆」改为「全圆 8px，分页顶 0」。
- wrapper 与 .ant-table 同时加 `overflow: hidden !important` 裁掉超出圆角外的内容。
- 单元格级别全部 `border-radius: 0`，避免在行级产生额外的小凹角导致白边。

## 5. 行为变化与兼容性

| 维度 | 行为 |
|------|------|
| 筛选条 + 表格组合 | 筛选区（卡片）与表格是**视觉上独立**的两张圆角卡片，不做拼接；两者间有 `pb-4` padding。 |
| 分页区域 | 分页位于表格底部容器内部；顶部角为 0，使其与 tbody 底部贴合；底部角 8px 与 wrapper 一致。 |
| 横向滚动 / 固定列 | table-body 本身也有底部圆角；固定列的单元格圆角全部归零，不会出现突出的小角。 |
| 浅色/深色主题 | 圆角本身是几何样式，与主题色无关。关键是背景裁切通过 overflow 生效，深浅色下视觉表现一致。 |
| 空表 Table | Table 显示「暂无数据」时依然保持 8px 圆润外观。 |

## 6. 测试与回归建议

1. 在「用户管理」列表（含分页、搜索、角色下拉）观察 4 个圆角：应呈现对称 8px。
2. 浏览器窗口缩小到 1024px 宽触发横向滚动条 → 滚动条嵌入 wrapper 内部，滚动条两端不应突出圆角外。
3. 「AI 用户管理」页左右滚动（会员、邮箱、时间列很多），固定列靠近侧的角不应出现小方块凹角。
4. 分页区：分页左侧选中 1，右侧跳到末页，分页条左上/右上不应有圆角留白（白边）。
5. 空表：搜索一个不存在的用户名使 Table 返回 `list=[]` → 空态卡片依然有完整 8px 圆角。
6. 深色模式：上述 1–5 在深浅色切换后视觉表现同样对称（无浅色深色下边缘颜色差异）。
